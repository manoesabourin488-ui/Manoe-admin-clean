# Manoe-admin-clean
⚡ Manoë Admin Clean

Un GUI admin Roblox simple et propre, conçu pour fonctionner sur mobile et PC.

Cette version est la version sans guns de Manoë Admin.

✨ Fonctionnalités

* 📱 Compatible mobile
* 💻 Compatible PC
* 🖥️ Interface graphique simple
* ✈️ Fly
* 👻 Noclip
* ❤️ Fonctions liées au personnage
* 🔄 Compatible avec le respawn
* 🧹 Supprime automatiquement l’ancien GUI avant d’en créer un nouveau
* 🚫 Aucun système de guns dans cette version

📦 Installation

Clone le dépôt :

git clone https://github.com/manoesabourin488-ui/Manoe-admin-clean.git

Ou télécharge directement le fichier .lua depuis le dépôt.

🚀 Utilisation

1. Ouvre le fichier Lua du dépôt.
2. Copie le script.
3. Exécute-le dans un environnement Roblox compatible.
4. Le menu Manoë Admin apparaîtra à l’écran.

Ce projet est fourni à des fins d’expérimentation et de développement.

Utilise-le à tes propres risques.
